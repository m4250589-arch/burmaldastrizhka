# Бурмалдастрижка

Адаптивный демонстрационный сайт вымышленного барбершопа. Чистые HTML, CSS и JavaScript, без фреймворков и внешних зависимостей.

## Что работает

- Версия для телефона, планшета и компьютера; мобильное меню и навигация по разделам.
- Выбор услуги и мастера сразу из соответствующей карточки.
- Демо-форма: дата на ближайшие 30 дней, время с учётом длительности услуги, итоговая стоимость и подтверждение выбранных параметров.
- Прошедшее время недоступно, услуга должна завершиться до 21:00.
- Доступное модальное окно, управление клавиатурой, Escape и возврат фокуса.
- Локальные изображения и шрифт: без внешних CDN, аналитики, cookies и запросов к сторонним API.

**Это демонстрация, а не действующая запись.** Данные не отправляются и не сохраняются; реальные бронирования не создаются. Цены, мастера и адрес вымышлены. Фотография создана с помощью ИИ, портреты — стилизованные SVG-иллюстрации.

## Открыть и изменить

Сайт можно открыть через `index.html` или запустить из корня проекта:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000`.

| Файл | Что находится внутри |
| --- | --- |
| `index.html` | Тексты, разделы, карточки услуг и мастеров |
| `styles.css` | Цвета, шрифты, размеры, мобильная версия |
| `app.js` | Демо-запись, цены, длительности, имена мастеров |
| `assets/` | Фотография, значок и локальный шрифт |

При изменении услуг нужно обновить и видимые карточки/список в `index.html`, и справочник `services` в `app.js`.

## GitHub Pages

Все рабочие файлы лежат в корне. В **Settings → Pages** выбрать **Deploy from a branch → main → / (root) → Save**. Файл `.nojekyll` отключает обработку Jekyll. Сайт поддерживает публикацию в подкаталоге репозитория.

## Проверки и сборка

Node.js нужен только для проверок и подготовки `dist/`, но не для самого сайта. Установка пакетов не требуется.

```sh
npm run check
npm run build
```

Для реального барбершопа заменить демонстрационные данные, добавить контакты и подключить настоящий сервис записи. Не менять сообщения о демо на «бронь подтверждена», пока сервер действительно не создаёт запись.
